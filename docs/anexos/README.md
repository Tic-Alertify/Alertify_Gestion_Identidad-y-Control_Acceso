# Anexos del Proyecto Alertify

Este directorio contiene los archivos y documentos que respaldan el trabajo de integración del módulo de identidad y control de acceso. Estos recursos complementan el documento principal y proporcionan la evidencia técnica de la ejecución del proyecto.
